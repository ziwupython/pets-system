# pets-system
基于Vue3的宠物领养管理系统【2026原创】

## 一、介绍
本宠物领养管理系统是一个基于前后端分离架构的Web应用，旨在为宠物爱好者提供便捷的宠物领养服务平台。系统分为用户和管理员两个角色，用户可以完成注册登录、浏览宠物信息、查看宠物详情、对感兴趣的宠物进行点赞和收藏、发表评论以及发起领养申请。系统支持每人限定领养一只宠物的规则，确保领养资源的合理分配。管理员拥有完整的后台管理权限，可以对用户信息进行维护、管理宠物信息和分类、审批用户的领养申请等操作。宠物信息涵盖所属分类、名称、详细介绍、图片展示和领养状态等关键信息。系统还提供灵活的查询功能，用户可以根据宠物分类或名称快速检索目标宠物。整个系统采用现代化的技术架构，界面友好，操作简便，为宠物领养提供了高效的数字化解决方案。
